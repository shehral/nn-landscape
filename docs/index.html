Patterns this build

  • The open-source document-extraction stack (opendataloader-pdf, Unstructured, Unstract, docling) covers every tier from layout-aware parsing to LLM-driven JSON extraction, and all four are active on GitHub as of August 2026 — signaling continued commoditization of the extraction layer. Combined, these four projects exceed 114K GitHub stars.
  • Three distinct document-parsing benchmarks (ParseBench, lmms-eval, and the Documents-Parsing-Lab community notebook) are active simultaneously without OCR-3 scores published in any of them, creating a growing set of public comparisons where OCR-3's position is not visible.
  • MCP integration has emerged as a distribution channel expectation: pdf-reader-mcp, UltraRAG, and Unstract all use the protocol. Document extraction services without an MCP server risk defaulting out of MCP-native developer pipelines.
  • LandingAI's 'Agentic Document Extraction' product (2,395 stars, Apache 2.0, last pushed July 31, 2026) uses terminology identical to Nanonets' positioning and is not yet in the competitive registry — indicating the editorial grounding missed a named competitor for an extended period.
  • Community-run OCR benchmarking is operating independent of leaderboard-maintainer runs: TurboOCR claims >200 img/s on OmniDocBench, and Documents-Parsing-Lab benchmarks Nanonets alongside open-weight alternatives. The IDP Leaderboard and OmniDocBench are no longer the sole comparison surfaces shaping developer perception.
