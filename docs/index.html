Patterns this build

  • CPU-only deployment of sub-4B OCR VLMs is now a concrete reality: franken_ocr packages Baidu Unlimited-OCR (3B MoE) for GPU-free inference, and mica-ppocr brings PP-OCRv6 to JVM without Python dependencies. The GPU-free accuracy floor for commercial-grade OCR is rising.
  • Output certification is emerging as a distinct product pitch: pdfmux positions extraction auditing as a standalone layer that can sit above any OCR extractor and certify its output, signaling a market expectation shift from accuracy claims to verifiable accuracy.
  • OCR capability is being distributed as a plugin rather than an API call: dsh-vision-toolkit adds intent-aware OCR to text-only coding agents without touching a dedicated document API, widening the pipeline configurations where commercial OCR is bypassed.
  • Document-to-Markdown converters are proliferating as standalone open-source primitives: doc7 and DocMeld both target the same pipeline step (document to agent-ready Markdown), joining Firecrawl AnyDoc and opendataloader-pdf in a crowded open-source tier of the extraction market.
