The Visual Insensitivity Gap: Diagnosing When Vision-Language Models Fail to Use Visual Evidence

VLMs ignore question-relevant visual evidence on 40-97% of tested samples; VSI metric quantifies per-sample visual sensitivity gap.

Product
The finding that VLMs routinely ignore visual input despite being able to detect visual change suggests OCR-VLMs may be text-priming their outputs rather than attending to document structure. Downstream: phantom rows and fabricated headers may stem from this mechanism, not from a distinct hallucination pathway.
Research
The Visual Sensitivity Index provides a per-sample probe that identifies inputs where the model's visual tower perceives the change (0.72-0.79 accuracy on linear probe) but the output distribution does not respond. Applying VSI to OCR-3 test documents could localize which document types or page regions trigger insensitive generation.
