Patterns this build

  • Open-source OCR at high throughput is normalizing as a local alternative to cloud APIs: TurboOCR (>200 img/s, OmniDocBench), paddleocr-local (PaddleOCR-VL-1.6, #1 OmniDocBench v1.6), and modlens all benchmark against or deploy the same benchmarks used to evaluate OCR-3, without API dependency.
  • LlamaIndex is consolidating a vertically integrated document stack — parser (LiteParse), benchmark (ParseBench, CVPR 2026), retrieval (LanceDB partnership) — from the same organization. This positions LlamaIndex as the default open-source alternative to cloud extraction APIs for agent-native pipelines.
  • The open-source RAG stack is converging on layout-aware parsing plus multimodal vector storage: haiku.rag uses Docling/LanceDB, LlamaIndex uses LiteParse/LanceDB. Developer adoption of these stacks does not route through dedicated OCR cloud APIs.
  • Agent-native vision plugins (modlens 3.4K stars, dsh-vision-toolkit 787 stars) are establishing a distribution model where OCR/layout is delivered as an in-agent plugin rather than a standalone API call, bypassing per-page cloud pricing models entirely.
  • Structured JSON is the converging output format for document AI tools across the build's items (Unstract, parsehawk, pdfmux, modlens, dsh-vision-toolkit), compressing competitive differentiation toward accuracy, throughput, and cost-per-page rather than output format.
