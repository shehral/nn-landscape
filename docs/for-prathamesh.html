  • Inference-time hallucination detection without weight modification is converging across multiple methods this build cycle. Buyers face an increasingly fragmented evaluation landscape; a company that runs OCR-3 on multiple benchmarks controls more of the comparative narrative.
  • The OpenAI Navier-Stokes claim establishes a new reference point for multi-agent system capability demonstrations, independent of its mathematical validity. The 10,000-agent / 88-hour framing is a marketing narrative about agentic scale. This framing pattern — large agent counts + hard milestone + dramatic timeline — will recur from other frontier labs and may affect buyer perception of what 'agentic' means.

SOB benchmarks structured extraction from invoices, medical records, and PDFs across 5,000+ text and 209 image records using seven document types.

Product

24 arxiv

Hallucination as an Anomaly: Dynamic Intervention via Probabilistic Circuits (arXiv 2605.05953)

PCNet trains a probabilistic circuit over the LLM residual stream to flag hallucinations as geometric anomalies at each decoding step, without sampling or weight modification.

Product
If PCNet's inference-time anomaly gate can be applied to OCR-3's residual stream at generation time, it offers a per-token hallucination flag without architectural changes — relevant to the /parse and /extract endpoints where phantom rows appear.
Research
The density-estimator approach (exact NLL over residual stream) is complementary to the team's existing activation-patching line: patching identifies causal circuits; PCNet provides a real-time detection signal. No fine-tuning required makes the pilot cost low if inference logs are available.
