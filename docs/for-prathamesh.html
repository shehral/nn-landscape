Patterns this build

  • PDF-to-agentic-workflow tooling is accumulating substantial developer adoption independently of enterprise extraction APIs: book-to-skill (25K stars in 4 months) and second-brain both treat documents as context inputs to agent runtimes, routing around cloud OCR endpoints entirely.
  • The enterprise agent orchestration layer is consolidating around open-source platforms (MaxKB at 22K stars), which commoditizes the RAG and knowledge-management functions that sit above extraction and reduces the stickiness of proprietary agent products.
  • Consumer demand for local, offline OCR remains persistent and is not served by enterprise extraction APIs: two new entries this build (ocr-it, docwen) operate offline using Tesseract or basic converters, indicating a developer and SMB segment that is not upgrading to VLM-based extraction.
