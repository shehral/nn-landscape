  • Rust runtime adoption for OCR and document AI is accelerating: franken_ocr (Rust CPU wrapper for Unlimited-OCR), oxidizePdf (Rust PDF library), and xberg (Rust core with 15 language bindings) all surfaced this build, signaling a shift toward performance-critical, self-hostable document processing.

  • MCP is emerging as a primary interface for document access in agent frameworks: pdf-mcp, UltraRAG, and xberg all expose MCP endpoints for document data, while docling-api and Unstructured-IO add REST API layers — agent frameworks are treating documents as tool-call resources rather than pre-processed file blobs.
  • Open-source document ETL is converging on agent-pipeline output formats: MinerU, doc7, Unstructured-IO, and unstract all produce LLM-ready Markdown or structured JSON as primary output, aligning on a common format expectation driven by RAG and agentic-workflow adoption.
