Patterns this build

  • All three top frontier labs shipped vision-capable models accepting PDF and image input in the first four days of September 2026 (Fable 5.1, GPT-6 Astra, Gemini 3.8 Flash). Developer comparison articles are now framing them as document-workflow alternatives, compressing the context in which customers evaluate specialized extraction against general-purpose APIs.
  • Three independent arXiv papers this build converge on table structure as the highest-hallucination regime in document VLMs, proposing different mitigations: multi-VLM structural consensus (PrismAlign), cross-architecture circuit localization (arXiv:2609.29048), and RL-based reward sharpening (DocPO). The techniques are complementary rather than competing.
  • Document parsing vendors are stratifying pricing by accuracy tier: Reducto now offers three tiers ($0.01 parse, $0.02 extract, $0.04 deep extract) and LandingAI DPT-3 plans per-character routing. Both reflect deliberate product-line segmentation by cost vs. accuracy, establishing reference prices that enterprise customer evaluations will now cite.
  • Lightweight proxy models for on-the-fly VLM hallucination detection are consolidating: NTP-based features (arXiv:2509.20379) and two-token ensemble methods (arXiv:2609.10244) both achieve VLM-level detection without secondary VLM calls. Both papers suggest deployment-ready confidence gate implementations at negligible inference overhead.
  • A new class of developer-first document API entrant (LandingAI DPT-3 Gen2, Infrrd IDPForge) is targeting self-serve workflows with model-specific pricing and BYOK routing. Neither names Nanonets as a comparison target, suggesting Nanonets is not in the default reference set for this entrant cohort.
