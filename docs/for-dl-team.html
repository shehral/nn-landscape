NaviDC-OCR: Navigating Document Parsing Across Digital and Camera-Captured Documents

NaviDC-OCR (2608.12898): 1.2B VLM with deformation-aware learning targets hallucination and redundant generation in end-to-end document parsing; open-source.

Product
NaviDC-OCR's content-structure decoupled learning — separating formula grammar and table structure from layout representation — is a direct architecture response to the hallucination modes the team tracks (structural hallucinations, phantom rows in tables). At 1.2B params and open-source, it is a viable low-cost baseline for the team's hallucination evaluation suite.
Research
Deformation-aware learning for camera-captured document distortion addresses a failure mode in the geometric-distortion → cascading layout error chain, which is distinct from the phantom-row and repetition-loop categories. The adaptive sampling mechanism for high-resolution complex layouts is worth reading alongside the team's existing activation-patching work.
