Patterns this build

  • Three this-build papers apply distinct diagnostic probing methods to VLM hallucination: PrismAlign uses structural Bayesian priors; the OCR-specialist paper uses causal attention-head interventions; the contrastive decoding paper uses layer-level probes. Mechanistic interpretability tooling for document VLMs is now an active research area in its own right, not just a theoretical framework.
  • Open-source OCR VLMs at 1–1.2B parameters are reaching 96+ on OmniDocBench v1.6, establishing a benchmark tier where model size no longer predicts performance rank. TeleOCR (1.2B) and OvisOCR2 (0.8B, from prior builds) both exceed 96 on v1.6, while larger commercial systems have not published v1.6 scores.
  • Multi-VLM ensemble approaches are appearing as a structured response to single-model table hallucination: PrismAlign aggregates three open-source VLMs using Bayesian decision rules rather than training a new model. This ensemble-as-calibration pattern may represent a lower-cost alternative to model retraining for table accuracy improvements.
  • OmniDocBench v1.6 (MGAM methodology) is becoming the primary public scoring surface for open-source document parsers, with TeleOCR, OvisOCR2, PaddleOCR-VL-1.6, and MinerU2.5-Pro all submitting v1.6 results this and recent builds. The IDP Leaderboard (where OCR-3 leads) and OmniDocBench v1.6 now cover different competitive populations, creating a benchmark fragmentation that complicates single-number positioning.
