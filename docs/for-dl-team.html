Patterns this build

  • MCP integration is consolidating as the default agent-pipeline interface for document extraction: three items (pdf-reader-mcp, Unstract, ade-cli) explicitly expose OCR or structured extraction as MCP tools, creating a distribution channel that bypasses REST API registration and pricing.
  • GPU-accelerated open-source OCR inference is closing the throughput gap with managed APIs: TurboOCR exceeds 200 img/s on OmniDocBench via TensorRT FP16, reducing the operational advantage of managed services for high-volume document processing.
  • Mechanistic interpretability tooling is maturing from research prototypes into standalone production-grade frameworks: CLT-Forge, Llamascopium, J-Wash, and Subtext all launched or had major updates in 2026, covering attribution graphs, SAE training, Jacobian Lens alignment, and activation visualization.
