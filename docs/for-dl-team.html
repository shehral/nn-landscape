Patterns this build

  • Per-page pricing is converging on sub-$0.01 as a competitive threshold: Reducto r-1 ($0.01 all-in), LandingAI DPT-3 Verity (projected under $0.01 on mixed workloads), and Mistral OCR 4 ($0.004 with batch discount) all target or claim this price point. Pricing has moved from a quality differentiator to a table-stakes constraint.
  • Structural hallucination in tables is crystallizing as a distinct research subfield: PrismAlign, SHROOM-Visions 2026, and FormStruct-Bench all specifically target tables, and the shared-task format of SHROOM-Visions suggests community benchmarking around this problem is stabilizing.
  • Mechanistic interpretability methods from LLM research (transcoders, sparse autoencoders, steering vectors, causal patching) are being systematically applied to VLMs at the circuit level. Three independent papers this build all address VLM hallucination via internal circuit analysis rather than behavioral evaluation alone.
  • Document parsing benchmarks are proliferating faster than evaluation protocols can standardize: ExtractBench (schema-guided), FormStruct-Bench (table-form structure), LongDocBench (long-document hierarchy), and TeleOCR's OmniDocBench v1.6 results all appear in the same build window, each targeting different document types. Cross-system comparison is increasingly difficult.
  • The self-serve developer API tier for document extraction is filling in: LandingAI DPT-3 Gen2, Infrrd IDPForge, and LlamaParse's ChatGPT plugin all launched or added capabilities in this build window. Three separate products are now competing for the developer API adoption path that Nanonets' Agentic Data Extraction API occupies.
