When Do VLMs Help Arabic Manuscript OCR? A Cross-Dataset Study

Eight-dataset cross-study: VLM conditioning on OCR output helps only when base OCR provides recoverable anchors ('OCR-prior recoverability principle').

Product
The 'OCR-prior recoverability principle' implies hybrid VLM-over-OCR pipelines degrade on documents where base OCR provides no usable anchors — a known failure mode for severely degraded scans. This is a concrete failure boundary to test in any document pipeline that chains traditional OCR with VLM correction.
Research
The cross-dataset evaluation structure (eight Arabic text domains, four system types) is a methodology applicable to hallucination evaluations across document degradation levels, not just Arabic script.
