Patterns this build

  • Three OSS extraction libraries this build (ExtractThinker, Lexoid, RapidDoc) replicate the managed extraction API surface — schema-based output, multi-format input, LLM-backed parsing — without any per-page pricing. The pattern is consistent with prior builds and represents a structural pressure on the make-vs-buy calculus for document AI startups.

The diversity of approaches reflects that no single mitigation method has achieved consensus.
  • Two mechanistic interpretability infrastructure tools surfaced this build (steering-vectors, nnterp), both providing unified, architecture-agnostic APIs that lower the barrier to running patching, probing, and steering experiments across different transformer families — relevant to the team's cross-architecture hallucination work.
  • On-device OCR deployment (react-native-executorch, german-ocr as a self-hostable fine-tune) is absorbing use cases that previously required managed cloud APIs. Two of the 22 items this build explicitly target local/edge deployment with no per-call cost, a pattern that has appeared in each of the last four GitHub-only builds.
