Collapse, Not Complexity: Failure-Conditioned Decomposition Repair for End-to-End Document Parsing

End-to-end doc VLMs fail via repetition collapse, not input complexity; decompose-and-re-parse repairs 83% of recurrent failures.

Product
Degenerate-repetition failures in document parsers stem from structural collapse, not input complexity — adding token budget or reasoning mode does not repair them. A decompose-and-re-parse step is tractable and does not require model retraining.
Research
The paper's collapse-detection method (tracing output divergence in the ordinary pass) offers a practical diagnostic for OCR-3's repetition-loop failure mode. The finding that 83% of collapses recur under reasoning mode updates the prior that chain-of-thought mitigates this class of error.
