Patterns this build

  • Table extraction evaluation is shifting from string-match metrics (TEDS) to semantic evaluation: three builds this week surface benchmarks that expose failures TEDS tolerates. The implication is that published TEDS-based leaderboard positions understate real-world accuracy gaps.
  • Inference-time and training-time interventions for repetition loops are converging on the KV cache as the leverage point: LoopGuard prunes the cache to break attention loops, while ReLoop's closed-loop training embeds a verification pass before the KV cache is finalized.
  • Domain-specific document benchmarks are proliferating: FinDocBench (finance, cross-page continuity), Dr.DocBench (expert-level difficulty-aware), and DISCO (multi-domain heterogeneous) each address gaps in OmniDocBench that matter for enterprise procurement — but none yet includes OCR-3.

LoopGuard: Breaking Self-Reinforcing Attention Loops via Dynamic KV Cache Intervention

Plug-in KV cache guard detects attention-loop onset at inference time and prunes the feedback cycle to stop repetition; introduces LoopBench.

Product
Repetition loops on long documents are a production failure mode for OCR models; a plug-in inference-time guard that requires no model retraining would reduce truncated-output errors on high-page-count documents without requiring OCR-3 retraining.
Research
LoopBench is the first dedicated benchmark with explicit loop-inducing conditions and loop-oriented metrics — directly applicable to OCR2-3B evaluation on pathological documents such as repetitive tables and continuous-form layouts.
