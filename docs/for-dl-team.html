Patterns this build

  • MCP protocol is standardizing how AI agents consume document extraction: pdfmux, pdf-reader-mcp, Zipstack/unstract, and parsehawk all expose MCP servers this cycle, suggesting the protocol is becoming a table-stakes integration layer for document AI tools.
  • OCR-3 is absent from three active benchmarks simultaneously: ParseBench (CVPR 2026), lmms-eval (DocVQA/ChartQA), and opendataloader-bench (via pdfmux). Each uses distinct evaluation methodology; the absence compounds across separate evaluation communities.
  • Local-first and self-hosted document extraction is accelerating as a distinct product category: parsehawk, pdfmux, pdf-reader-mcp, doc7, and Zipstack/unstract all emphasize on-premise or local deployment this cycle, pointing to a regulated-enterprise segment that cloud-API offerings may not reach.
  • LlamaIndex has assembled a vertically integrated parser ecosystem — LiteParse (open parser), ParseBench (benchmark), and Parse-Flow (workflows) — all originating from the same lab. This depth of investment positions LlamaIndex as a multi-product competitor rather than a single managed-service alternative.
  • Mechanistic interpretability tooling is fragmenting into specialized functions: pyvene (activation patching), CLT-Forge (cross-layer transcoders), axbench (method benchmarking), Subtext (visualization), and J-Wash (Jacobian Lens editing) all appeared this cycle as distinct tools. Research teams can now compose MI pipelines from modular components rather than building from scratch.
