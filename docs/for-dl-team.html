Patterns this build

  • Parsing-free document retrieval is consolidating as a distinct architectural pattern: VisRAG and Snappy both bypass OCR extraction in favor of querying VLMs directly over page images, reaching 979 and 90 GitHub stars respectively. This is not an isolated experiment — it is a repeatable pattern that trades extraction accuracy for retrieval speed.
  • GLM-OCR (Z.ai) is gaining self-hosted deployment ecosystem traction: a community-built FastAPI+WebUI server for GLM-OCR shows developer interest in running the model locally. Combined with PaddleOCR-Skills packaging PaddleOCR-VL for agent workflows, open-weight OCR models are becoming easier to embed in developer pipelines than commercial API alternatives.
  • Reward-model and RL fine-tuning techniques are being applied to VLM visual alignment (LightRFT, Visual-ERM), signaling that the field is moving from behavioral prompting to training-time corrections for visual tasks — an approach that could directly affect hallucination rates in production VLMs.
  • Docling (IBM Research) appears as the default open-source parsing layer in community RAG stacks (NexusRAG), reinforcing its role as the open-weight reference architecture for document-ingestion pipelines. Each new stack that defaults to Docling widens the gap between Docling's ecosystem footprint and paid alternatives.

Does parsing-free VLM retrieval (VisRAG, Snappy) represent a structural threat to Nanonets' extraction value proposition, or does it validate the accuracy case for specialized OCR?
