Patterns this build

  • Three distinct MCP servers for PDF processing released in this build (pdf-reader-mcp, pdf-mcp, Nutrient DWS MCP), signaling convergence on MCP as the standard agent-document interface pattern.
  • GRPO for VLM structural hallucination elimination is now accessible via at least two production-grade frameworks (ms-swift, Relax), lowering the barrier for competitors to replicate FireRed-OCR-2B's Format-Constrained GRPO result.
