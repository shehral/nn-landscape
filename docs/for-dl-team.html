Patterns this build

  • Local-first and self-hosted document extraction tools are proliferating — parsehawk, pdfmux, Unstract, and MinerU all published or updated this week, each targeting the same JSON-schema extraction surface as cloud APIs. The pattern suggests enterprise data-residency requirements are a primary adoption driver.
  • VLM evaluation tooling is consolidating around three standardized harnesses (lmms-eval, evalscope, ParseBench) that each cover a different evaluation philosophy — OCR accuracy, agent-task success, and customizable benchmarks. Publishing scores across all three is becoming expected for competitive VLMs.
  • GRPO-based training is appearing across multiple model families (Qwen-VL-Finetune supports GRPO; ms-swift supports GRPO for 600+ models). FireRed-OCR-2B showed that Format-Constrained GRPO eliminates structural hallucinations. This suggests GRPO may become the standard training method for improving VLM structural correctness.
  • Serving infrastructure for VLMs (SGLang, ms-swift) is maturing to the point where self-hosting a document-capable VLM is a commodity operation. This shifts the competitive basis from model quality alone to workflow integration, API ergonomics, and accuracy SLAs.
  • ParseBench (LlamaIndex) continues to grow — 536 stars, 75 forks, CVPR 2026 — without OCR-3 or most named IDP competitors participating. The benchmark is becoming a de facto agent-task parsing standard before any dominant player claims the top position.
