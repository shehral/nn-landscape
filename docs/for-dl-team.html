  • Frontier model price-performance compression is reaching the document-extraction tier. The cost premium for a specialized OCR API vs. a frontier vision API is narrowing without any published accuracy comparison favoring the frontier side.
  • SHROOM-Visions 2026 is consolidating character-level VLM hallucination evaluation into a benchmark infrastructure with 28 participant systems. The shared task produces a standardized taxonomy and scoring methodology for the class of hallucination (substitutions, insertions, deletions at character boundaries) that OCR-specialized VLMs produce. This is the first well-curated shared task targeting that specific failure mode.
  • Data-centric training refinement using production residual errors is converging as a technique across multiple concurrent papers. WeVisDoc's Stage II (residual-error-guided data allocation) and FinixDoc (difficulty-stratified evaluation driving targeted data construction) both demonstrate this pattern at 4B scale, consistent with arXiv:2609.01575 on 35B MoE from the prior build. The common finding: production model confidence residuals are a more reliable training-data selection signal than human-annotated difficulty labels.
