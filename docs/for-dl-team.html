Patterns this build

  • Sub-3B document VLMs are achieving competitive or SOTA accuracy: MonkeyOCRv2's 0.7B model beats 3B-class specialists on MDPBench, while Cohere Parse 5 delivers enterprise extraction with a 2.3B model at the same price floor as larger commercial systems. The efficiency-accuracy frontier for document specialists is compressing rapidly.
  • Causal interpretability is converging on small clusters of attention heads as the locus of hallucination mechanisms. Vision-Default, Prior-Override (2606.28273) isolates 2.5-4.8% of heads governing knowledge-over-vision failures; this is the same architectural pattern implicated in phantom-row generation. The tooling for head-level causal intervention is now mature enough for targeted application on document VLMs.
  • Mechanistic interpretability methods face a new robustness caveat: IRN-derived features are not stable under minor input perturbations. The Misery of Mechanistic Interpretability (2609.15533) shows this across 5 model families, which complicates research that infers causal mechanisms from single-point IRN analyses.
  • Evaluation methodology for generative document parsing is maturing into specialized frameworks: SCORE (2509.19345) introduces token-level hallucination vs. omission diagnostics and spatial-tolerance table evaluation. Combined with the prior build's SHROOM-VLMs and Dr.DocBench, a distinct evaluation ecosystem is forming around generative-output document parsers rather than traditional OCR metrics.
  • Numeric grounding in document images is an undercharacterized accuracy risk: Visual Anchoring Bias (2605.11218) shows numeric anchors bias VLM judgments more strongly than severe image degradation. For financial document extraction — invoices, receipts, AP workflows — this suggests a systematic error source that existing benchmarks may not be measuring.

Product
